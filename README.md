# Sphaera website — prototype v1

A responsive static website prototype for **Sphaera — Classical Astrology & Celestial Studies**.

## What's included

- `index.html` — homepage sections and consultation cards
- `css/style.css` — responsive design system and styles
- `js/main.js` — mobile navigation and current year
- `legal-notice.html`, `privacy.html`, `terms.html` — placeholder legal pages, **not publication-ready**

## Preview locally

Open `index.html` in a browser. For best results, use a local web server, but this simple site also works when opened directly as a file.

## Publish using GitHub Pages

1. Create a GitHub account or sign into your existing account.
2. Create a repository. For a user site, name it exactly `YOURUSERNAME.github.io`; for a project site, use another repository name.
3. Upload the contents of this folder to the repository (the `index.html` must be at the repository root).
4. Open repository **Settings → Pages**.
5. Under the publishing source, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
6. Wait for the deployment and open the published URL.

## Before publishing for business use

Replace:
- `CONTACT_EMAIL_HERE` in `index.html` with a real business contact address
- provisional brand/domain choice if needed
- practitioner biography and credentials/background
- service scope, actual prices, and delivery timeframe
- contact/order process, including secure handling of birth details
- placeholder legal pages with properly reviewed information for your business and Spanish/EU requirements
- final PayPal payment links only after service descriptions, terms, and checkout process are established

The website currently **does not collect customer birth details or process payments**. The contact button is a placeholder email link.
